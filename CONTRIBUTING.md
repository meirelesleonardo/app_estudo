# Guia de Contribuicao

Obrigado por contribuir.

## Como este projeto evolui

Este repositorio adota estrategia de evolucao incremental com documentacao primeiro.

Antes de propor implementacao, abra discussao documental:
1. Etapa e subetapa impactadas.
2. Objetivo e criterio de conclusao.
3. Riscos e dependencias.
4. Referencias para backlog, ADR e roadmap.

## Tipos de contribuicao aceitos nesta fase

- melhoria de documentacao;
- refinamento de roadmap e backlog;
- propostas de arquitetura;
- proposta de padroes de governanca;
- revisoes de clareza e rastreabilidade.

## Fluxo de trabalho

1. Crie branch com padrao definido em docs de governanca.
2. Atualize documentos impactados.
3. Garanta rastreabilidade cruzada (IDs e links).
4. Abra Pull Request com contexto completo.

## Pull Request

Inclua:
- objetivo da mudanca;
- etapa/subetapa afetada;
- artefatos alterados;
- impacto esperado;
- checklist de rastreabilidade.

## Checklist de PR

- Nao houve implementacao de codigo fora do escopo aprovado.
- Itens de backlog afetados foram atualizados.
- Links para roadmap e ADRs relevantes foram incluidos.
- Linguagem clara e consistencia terminologica.
