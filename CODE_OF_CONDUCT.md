# Codigo de Conduta

## Compromisso

Este projeto busca um ambiente colaborativo, respeitoso e inclusivo.

## Comportamentos esperados

- respeito em toda comunicacao;
- feedback tecnico construtivo;
- abertura para revisao e aprendizado;
- foco em colaboracao.

## Comportamentos inaceitaveis

- assedio ou intimidacao;
- linguagem ofensiva ou discriminatoria;
- ataques pessoais;
- exposicao indevida de dados sensiveis.

## Aplicacao

Mantenedores podem solicitar ajustes, moderar discussoes e, em casos graves, restringir participacao.

## Reporte

Abra issue privada para relatar incidentes de conduta, com contexto objetivo e evidencias quando possivel.
