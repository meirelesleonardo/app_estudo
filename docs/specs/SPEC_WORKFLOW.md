# Fluxo de Criacao de SPEC

## Regra principal

SPEC nao nasce automaticamente.

## Fluxo obrigatorio

1. Refinar etapa.
2. Refinar subetapas.
3. Definir objetivo, conteudo, fontes, estrategia, dificuldade, tipo de midia, metricas e criterio de sucesso.
4. Validar escopo e nao escopo.
5. Aprovar gate formal pre-SPEC.
6. So entao criar SPEC.

## Checklist antes da SPEC

- Etapa existe no roadmap.
- Subetapa existe e tem criterio de conclusao.
- Backlog relacionado esta priorizado.
- Dependencias estao declaradas.
- Riscos estao mapeados.
- Metricas estao definidas.
- Gate pre-SPEC registrado como aprovado.

## Qualidade da SPEC

- pequena e incremental;
- rastreavel;
- independente;
- testavel em termos de criterio de aceite (quando chegar a implementacao).

## Bloqueios comuns

- falta de criterios de sucesso;
- escopo amplo demais;
- dependencia nao mapeada;
- falta de fonte ou curadoria para o modulo.
