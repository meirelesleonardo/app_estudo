# Organizacao de Prompts

## Objetivo

Padronizar prompts reutilizaveis para continuidade do projeto sem perda de contexto.

## Estrutura sugerida

- prompts de continuidade de etapa;
- prompts de refinamento de subetapa;
- prompts de pre-SPEC;
- prompts de revisao de rastreabilidade.

## Regras

- todo prompt deve declarar objetivo da sessao;
- todo prompt deve citar etapa/subetapa;
- todo prompt deve listar entregaveis esperados;
- nenhum prompt deve solicitar codigo quando etapa nao estiver pronta.

## Modelo curto

- Contexto atual
- Objetivo da sessao
- Restricoes
- Artefatos a atualizar
- Criterio de conclusao
