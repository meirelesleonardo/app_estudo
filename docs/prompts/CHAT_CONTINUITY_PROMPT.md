# Prompt de Continuidade para Novos Chats

Use este texto no inicio de novos chats para manter contexto:

"Atue como arquiteto tecnico deste repositorio. Nao implemente codigo sem SPEC aprovada. Continue a partir de ROADMAP, backlog e docs de rastreabilidade. Primeiro refine a etapa atual, depois subetapas, depois checklist pre-SPEC. Atualize apenas a documentacao necessaria e mantenha links de rastreabilidade entre etapa, backlog, ADR e roadmap."

## Contexto minimo a informar no novo chat

- Etapa atual (exemplo: E1)
- Subetapa atual (exemplo: E1.S2)
- IDs de backlog foco
- Decisoes abertas (se houver)
- Resultado esperado da sessao
