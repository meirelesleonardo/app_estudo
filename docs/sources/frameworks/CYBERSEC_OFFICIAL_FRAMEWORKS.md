# Fontes Oficiais Prioritarias - Cyber Security

## Objetivo

Formalizar fontes oficiais e normativas prioritarias para curadoria
confiavel de conhecimento tecnico em Cyber Seguranca.

## Frameworks e normativas prioritarias

- OWASP;
- NIST;
- CIS Benchmarks;
- MITRE ATT&CK;
- CISA;
- RFC Editor;
- Linux Foundation;
- documentacoes oficiais de protocolos;
- documentacoes oficiais de cloud providers.

## Regras de uso

- prioridade para documentos originais e versoes vigentes;
- uso de resumo secundario somente com vinculo para fonte primaria;
- toda citacao deve carregar source_id, versao e data de revisao.

## Politica de confiabilidade

- default: alta para fonte oficial vigente;
- media para guias de implementacao complementar;
- baixa/experimental para conteudo sem rastreio institucional.
