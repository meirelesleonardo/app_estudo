# Sources - Trusted Knowledge Sources

## Objetivo

Centralizar a base de conhecimento confiavel do projeto com governanca formal,
separacao entre fonte aprovada e experimental, e politica explicita de uso por IA.

## Estrutura

- english/
- cybersec/
- concursos/
- frameworks/
- labs/
- operational/
- experimental/
- governance/

## Principios

- toda fonte deve ser identificada, classificada e versionada;
- toda fonte deve declarar mantenedor, risco e prazo de revisao;
- conteudo sem curadoria nao pode alimentar automacao de IA;
- fonte experimental nao entra em pipeline operacional sem validacao.
