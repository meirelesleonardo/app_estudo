# Sources - Experimental

## Objetivo

Separar fontes experimentais do fluxo confiavel para evitar contaminacao da base oficial de IA.

## Regras

- toda fonte experimental inicia com status sandbox;
- proibido uso automatico em cards, simulados e sync pipeline;
- uso permitido apenas para analise controlada com revisao humana.

## Criterio de promocao

Para promover para aprovado:
- duas revisoes consecutivas positivas;
- rastreabilidade completa;
- risco residual documentado e aceito.
