# Glossario

- Curadoria: processo de selecao e qualificacao de fontes.
- Connected speech: fenomenos de fala corrida com ligacoes e reducoes.
- Rastreabilidade: capacidade de ligar objetivos, backlog, decisao e entrega.
- Etapa: bloco macro do roadmap.
- Subetapa: decomposicao operacional de uma etapa.
- Backlog: fila priorizada de trabalho.
- SPEC: especificacao incremental de uma unidade de trabalho.
- ADR: registro de decisao arquitetural.
- MVP: menor versao viavel para validar o fluxo central.
